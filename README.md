# Typing Speed Tester

## 📌 Overview

Typing Speed Tester is a web-based application that measures typing speed and accuracy in real time.

The project helps users practice typing while tracking performance metrics such as words per minute (WPM) and typing accuracy.

---

## ✨ Features

- Real-time typing speed calculation
- Accuracy tracking
- Interactive typing interface
- Timer functionality
- Responsive design

---

## 🛠 Tech Stack

- HTML
- CSS
- JavaScript
